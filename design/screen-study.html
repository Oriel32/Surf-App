SurfCore · screen study · v2

Glassy

Four screens for the Israeli surf forecast, in the aqua art direction. The aqua is earned, not applied: the hero card floods with it only when the sea is genuinely glassy, so opening the app to a wall of blue is itself the forecast. Every number came out of a live SurfCore run against the real APIs this morning — the screens were chosen for the four states that are easy to get wrong, not the four that look best.

A glassy morning with nothing in it. The card floods aqua because the surface is beautiful — and still says 42, because the swell is ankle-high. Colour carries sea state, never the verdict, so the two facts don't have to agree. The buoy read 0.56 m and the model read 0.56 m for the same hour; the delta that proves it moved to Layer 2, where an analyst can find it.

Sunday is the day, and you can see that without reading a number — the aqua row is the swell arriving. Each row is a promise about a time of day, never a daily average: Thursday scores 40 but only between midnight and 02:00, and the row says so. Three facts per row and no second numeral, so the eye can run down the column of scores in one pass.

The two states apps forget, both real this morning. The forecast for Haifa genuinely failed in the live run, so the screen says so and offers a retry rather than a spinner over an empty card. Below it, Shikmona still answers HTTP 200 with a frozen 4.09 m storm reading from January — the number the app must never print. The buoy section degrades on its own and says why, in words, without a date the user has to do arithmetic on.
